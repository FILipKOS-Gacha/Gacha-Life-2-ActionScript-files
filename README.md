# Gacha-Life-2-ActionScript-files
Gacha Life 2's ActionScript files or alternatively Gacha Life 2's Source code.

The files taken from the game come from PC version, Android or iOS versions may differ from each other. Small reminder that Lunime might send a takedown request on this repo. So don't get your hopes for this repo to stay for many years...or even months.

# NOTE
You cannot compile the AS files, if you want to truly make changes to the game to make a bug-fixed version of it, you need to manually edit the files inside the .swf file using FFdec. And again, the code is from PC version, use the code to analyze how the game exactly works or how it functions...or to see how many bugs are there.
